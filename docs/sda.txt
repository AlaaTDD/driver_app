# Flutter + Supabase Codebase Auditor — v3.0
> ** taxi_app App** | User + Driver Roles | BLoC/Cubit | Supabase

---

## 🎯 Context (اقرأ قبل أي حاجة)

هذا المشروع تطبيق  taxi_app يحتوي على:
- **Roles:** user, driver (+ admin في DB)
- **State Management:** BLoC في بعض الـ features، Cubit في أخرى — مختلطة
- **Architecture:** Feature-first، بعض الـ features عندها domain layer (trips)، وبعضها لا (wallet)
- **Tables الحقيقية:** `trips`, `trip_offers`, `driver_locations`, `messages`, `notifications`, `wallet_transactions`, `driver_wallets`, `user_wallets`, `withdrawal_requests`, `ratings`, `complaints`, `users`, `drivers_profile`, `vehicle_types`, `pricing_config`, `coupons`, `coupon_usages`, `user_coupons`, `support_messages`, `user_presence`
- **Views/RPC موجودة:** `driver_earnings_summary` (view)، `request_driver_withdrawal` (RPC)
- **ملفات تحتاج انتباه:** أي `.dart.bak`، أي ملف في `features/shared/presentation/*/data/` (data layer داخل presentation — anti-pattern)
- **Schema issues معروفة:** trips table فيها duplicate columns (pickup_address = origin_address)، وفيها 9 أعمدة 100% NULL (features غير مكتملة)
- **مرجع قاعدة البيانات:** `docs/Supabase Snippet PostgreSQL Schema X-Ray Introspection Report.csv`

## 📋 الخريطة المطلوبة

ابحث في هذه الطبقات بالترتيب:

```
UI          → features/*/presentation/screens, pages, widgets
State       → bloc/, cubit/ (events, states, transitions)
Data        → repository/, datasource/, models/, mappers/
Services    → services/ (supabase_service, fcm_service, location_service…)
DB          → CSV reference + RPC functions + RLS policies
Realtime    → cell_subscription_service, trip_broadcast_service, streams
Shared      → features/shared/presentation/ (rating, messages, notifications, chatbot, complaints)
```

## 🚨 افحص هذه المشاكل صراحةً

| Code | ابحث عن |
|------|---------|
| `SCHEMA_MISMATCH` | حقل في Model غير موجود في CSV أو العكس |
| `WRONG_FK` | filter بـ `wallet_id` بينما FK الحقيقي مختلف |
| `STREAM_LEAK` | StreamSubscription بدون `cancel()` في `dispose()` |
| `NULL_CRASH` | `!` أو `.first` بدون null check على بيانات Supabase |
| `STALE_BAK` | ملف `.dart.bak` لا يزال يؤثر على السلوك |
| `ANTI_PATTERN` | data layer داخل presentation folder |
| `BROKEN_FLOW` | event/state لا يُعالَج أو يُطلَق ولا أحد يسمعه |
| `MISSING_RLS` | عملية insert/update بدون policy مناسبة |
| `NO_PAGINATION` | query بدون `.limit()` على جدول قابل للنمو |
| `HARDCODED` | قيمة ثابتة يجب أن تكون في constants/config |
| `DI_BYPASS` | Cubit/Bloc يُنشئ Repository مباشرة (بدون injection) |
| `EMPTY_STATE` | قائمة بدون حالة empty في الواجهة |

## ⚙️ طريقة العمل

1. **افهم الـ feature** — ما المرادفات داخل هذا المشروع بالذات؟
2. **ابحث في الكود** — اقرأ الملفات فعلاً، لا تكتفِ بالأسماء
3. **تحقق من CSV** — كل Model اذكر Column مقابله في الجدول
4. **تتبع السلسلة** — من UI حتى DB وعودةً
5. **افحص قائمة الـ 12 مشكلة** واحدة بواحدة
