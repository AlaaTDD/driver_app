## 📁 ملاحظات على البنية المعمارية

> **تحذير عام:** كثير من رسائل الخطأ موجودة في البلوكات والكيوبتات (`BLoC/Cubit`) التي **لا تملك BuildContext**. هذا يعني أنه لا يمكن استخدام `AppLocalizations.of(context)` مباشرة فيها.
>
> **الحل الموصى به:** بدلاً من تمرير نصوص عربية كـ Strings في البلوك، استخدم **أكواد خطأ كـ enum** وترجمها في طبقة الـ UI:
>
> ```dart
> // في البلوك
> enum WalletError { insufficientBalance, walletNotFound, withdrawalPending }
> emit(WalletFailureState(error: WalletError.insufficientBalance));
>
> // في الـ Widget
> final msg = switch (state.error) {
>   WalletError.insufficientBalance => l.errorInsufficientBalance,
>   WalletError.walletNotFound => l.errorWalletNotFound,
>   ...
> };
> ```
